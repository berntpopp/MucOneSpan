# Milestone M0: Adversarial Review Dispositions

| Finding ID | Severity | Area | Status | Disposition & Action Plan |
|---|---|---|---|---|
| **G1** | High | Genomics/UX | **ACCEPTED** | **Negative Call & Dropout Semantics:** Do not use unconditional `BENIGN`. Replace with `NO_PATHOGENIC_VARIANT_DETECTED`. Gated strictly on: (1) two independently confirmed alleles, (2) verified coverage depth, (3) length within validated sensitivity envelope. Single observed length in amplicon mode will be marked `INCONCLUSIVE` (with explicit `possible_allele_dropout` caveat) unless verified diploid homozygous by orthogonal evidence. |
| **G2** | High | Genomics | **ACCEPTED** | **HGVS 20.05 Nomenclature:** Repeat-relative coordinate (e.g. `repeat_45:c.59dupC`) is the primary invariant clinical coordinate. Transcript `c.` (e.g. `c.530dupC`) is emitted only when mapped and verified against authentic transcript sequence context under HGVS 20.05 rules (3' shift, dup vs ins); otherwise emit `transcript_coordinate_unresolved`. Fix `delinsAT` definition across docs and tests. |
| **G3** | High | Genomics | **ACCEPTED** | **Haploid Majority Variant Safety:** Never silently overwrite borderline heterozygous calls (AF 0.20–0.80) to `0/0` on an unseparated cluster. Retain variant and flag as mixed allele evidence; mark reconstruction as `ambiguous_reconstruction` or `INCONCLUSIVE` rather than emitting a false negative. |
| **G4** | Med | Genomics | **ACCEPTED** | **Usable Depth & Spanning Reads:** Clarify definition of usable depth: primary alignments anchoring both 5' and 3' flanks. Exclude secondary alignments from allele support counts. |
| **G5** | Med | Genomics | **ACCEPTED** | **Statistical Power & Metrics Integrity:** In evaluation reports, include Wilson score confidence intervals for all sensitivities/specificities. Ensure failed executions remain strictly in the denominator. Record C6 as complex indel/structural variants (note absence of pure SNVs in simulation truth). |
| **G6** | Med | Genomics | **ACCEPTED** | **Split Sealing & Verification:** Test split truth directory will remain strictly separated and read-protected during development and validation tuning. Runner will require explicit `--split` matching manifest (`dev`, `val`, `test`). |
| **G7** | Low | Genomics | **ACCEPTED** | **Consensus bcftools Stderr:** Capture `bcftools consensus` stderr, detect skipped overlapping variants, and log warnings or transition to inconclusive if variants were dropped. |
| **S1** | High | Systems | **ACCEPTED** | **Subprocess Safety & Timeouts:** Implement per-stage timeouts in `tools.py`, create process sessions (`start_new_session=True`), and terminate process groups with `os.killpg` on timeout or cancellation. Distinguish SIGINT (`interrupted`) from execution failures. |
| **S2** | High | Systems | **ACCEPTED** | **Runner Durability & Exception Safety:** Evaluation runner writes incremental append-only JSONL with atomic commit/fsync. Worker exceptions are caught and recorded as structured failure records rather than crashing the batch. Resume checks artifact validity and hashes. |
| **S3** | Med | Systems | **ACCEPTED** | **Resource Budgeting for 45 GiB RAM:** Adjust thread and concurrency caps: Set `samtools sort -m 500M`. Restrict parallel sample runs to 4–6 workers with 4 threads each (or 8 with constrained memory) to avoid exceeding 45 GiB available RAM. Control OpenMP and BLAS threads. |
| **S4** | Med | Systems | **ACCEPTED** | **Portability & Path Elimination:** Remove hardcoded `/home/bernt-popp/` paths from defaults in `run_eval_pipeline.py` and `run_500_experiment.py`. Require CLI or environment arguments, or resolve relative to runtime environment. Strip machine paths from public artifacts. |
| **S5** | Med | Systems | **ACCEPTED** | **Atomic Commit & Ledger Integrity:** Implement single authoritative ledger writer with file locking (`fcntl.flock`), write-to-temp, `fsync` of file and directory, and atomic rename. Secondary ledgers (public/blinded) derived deterministically from authoritative ledger. |
| **S6** | Low | Systems | **ACCEPTED** | **Provenance Tracking:** Ingest git SHA, dirty flag, model directory hash, and config SHA in all ledger rows and evaluation metadata. |
| **U1** | High | UX | **ACCEPTED** | **Multiplicity Caveat in Report:** For single-cluster / unseparated alleles, do NOT render a false 50/50 balance bar. Explicitly render prominent caveat: "Single allele length observed; second allele not established (possible dropout or homozygosity)". |
| **U2** | High | UX | **ACCEPTED** | **Offline IGV & CSP:** Formulate a CSP that permits necessary offline local operations (`blob:`, `data:`, `'unsafe-eval'` if using compressed igv loader, or inline plain script without eval). Validate in Playwright that IGV loads tracks and renders canvas offline. |
| **U3** | Med | UX | **ACCEPTED** | **DOM Injection Defense:** Sanitize and escape all BAM read names, sample names, and annotation strings before injecting into HTML or JS contexts. |
| **U4** | Med | UX | **ACCEPTED** | **Print Optimization:** Ensure `@media print` uncollapses all `<details>`, forces high-contrast light styling, provides text fallback for IGV canvas, and outputs running sample headers. |
| **U5** | Med | UX | **ACCEPTED** | **Accessibility Scope:** Target WCAG 2.1 AA with AAA contrast enhancement (>= 7:1 normal text, >= 4.5:1 large text). Implement keyboard focusable tooltips, semantic headings, and `tabular-nums`. Document audit methodology transparently. |
| **U6** | Low | UX | **ACCEPTED** | **Playwright Assertions:** Assert presence of rendered track canvas elements, zero network requests (blocked and recorded), zero console errors, and zero unhandled rejections. |
