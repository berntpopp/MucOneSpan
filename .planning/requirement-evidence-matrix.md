# Production-validation requirement/evidence matrix

Date: 2026-09-14. Baseline: `d8390b3c244ef8f3240af74b92db12b50dfc77d1`.

This matrix describes the checked candidate before final source freeze and final
paired validation. “Implemented” means a bounded interface has focused source/test
evidence; it does not imply scientific promotion. Configuration-stage software
checks pass as recorded below. The actual Claude Fable 5.1 runtime-configuration
review is running; its outcome and final external review remain pending. The fixed
128-input paired final panel is also pending, with zero reserved seeds used.
Exposed development and cached equivalence results remain historical evidence.

Status terms:

- **Implemented — bounded**: the specified software behavior is present with a
  focused regression or controlled equivalence result.
- **Diagnostic only**: a tested measurement API or experiment exists but is not
  connected to production inference.
- **Promotion failed**: the candidate was tested and violated a predeclared
  scientific no-regression or adequacy rule; the default remains unchanged.
- **Unmet**: the requested scientific capability has not been delivered.
- **Pending**: final validation or review has not yet supplied evidence.
